# matter-bridge

A standalone Matter to MQTT bridge: a Matter controller (on rs-matter)
that commissions devices, keeps a subscription to each, and publishes what
they report on MQTT, with Home Assistant discovery and a plain JSON topic
scheme. See the README for the topics.

Part of [matter-bridge](https://github.com/pulzar-net/matter-bridge), maintained by
[Pulzar](https://pulzr.net). See the [user guide](https://oss.pulzr.net/matter-bridge/), the
[library guide](https://oss.pulzr.net/matter-bridge/library/index.html) and the
[API documentation](https://oss.pulzr.net/matter-bridge/api/matter_bridge/index.html).
